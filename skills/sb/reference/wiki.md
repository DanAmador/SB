# The wiki

The wiki's format and tools moved to the **wikibrain** skill
([github.com/DanAmador/wikiBrain](https://github.com/DanAmador/wikiBrain)), pinned in this repo's
`skills-lock.json` and installed beside sb by `install.sh`. Read its `reference/wiki.md`
(installed at `~/.agents/skills/wikibrain/reference/wiki.md`): the layout, properties, links, the
grounding invariant, writing a finding, and the commands. Every section this file used to have is
there under the same heading.

`sbmap wiki <command>` runs wikibrain's tools against the vault, exactly as before.
