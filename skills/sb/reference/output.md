# Writing for the owner

The general rules (line 1 is the action, ➡️ on every question, at most 5 items per group, one
two-minute next action) are the **Plain** output style,
[`output-styles/plain.md`](../../../output-styles/plain.md). With the style off, read that file and
follow it. Plain words: [SKILL.md](../SKILL.md#plain-words). Only the sb-specific rules are here.

- **Detail goes to the vault.** Evidence, reasoning, file lists and logs go into the ticket
  (`sbmap comment`), the handoff or the map; chat links to them.
- **Status emojis**, one meaning each: ✅ landed · 🎮 needs the owner's play · 👤 owner's call ·
  ⚠️ problem or unverified · ⏳ running · 🔒 rule · 🗺️ map change · 🆕 created · 💬 added to ·
  ♻️ reopened.
- **Tickets by name**, the number inside the link. In chat, any vault note is the line
  `sbmap uri <file> "<name> #NNN"` prints, pasted as is: never type an `obsidian://` link (the
  `vault-link-check` mod sends back one that won't open). In the vault, a wikilink (`sbmap link`).
- Estimates in hours, from commits ([the contract](contract.md)), with what the owner will *see*
  when it is done.
